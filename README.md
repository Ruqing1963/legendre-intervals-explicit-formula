# Primes in Legendre intervals over F_q[t]

**An exact explicit-formula algorithm, verification for d ≤ 10, and an anomaly in characteristic 2.**

Published on Zenodo: [10.5281/zenodo.23219609](https://doi.org/10.5281/zenodo.23219609).

[![DOI](https://img.shields.io/badge/DOI-10.5281%2Fzenodo.23219609-blue)](https://doi.org/10.5281/zenodo.23219609)

For monic $f\in\mathbb F_q[t]$ of degree $d$, the Legendre interval $\mathcal I_f=\lbrace f^2+s:\deg s\le d\rbrace$ is the function-field analogue of $[n^2,(n+1)^2]$. The Hayes–Weil estimate settles the range $q\ge d-1$; see the companion preprint v7, [10.5281/zenodo.23185896](https://doi.org/10.5281/zenodo.23185896), with code at [legendre-function-field](https://github.com/Ruqing1963/legendre-function-field). This repository treats the open range $q\le d-2$.

## Results

- **Algorithm.** The prime count $\Psi(f)=\sum_{P\in\mathcal I_f}\Lambda(P)$ is computed for all $q^{d-1}$ intervals at once, from the explicit formula. Every Hayes $L$-function is evaluated by a transform over the Hayes group, using an explicit basis of that group for every $\mathbb F_q$ (Proposition 3.1). The cost is about $d^2q^{d-1}$ operations, compared with about $q^{2d}$ for testing every polynomial.
- **Exactness.** The whole computation is also run in exact modular arithmetic: two primes, then the Chinese remainder theorem. The verification is therefore a proof, not a floating-point estimate.
- **Theorem 5.1 (computer-assisted).** Every Legendre interval contains an irreducible polynomial in the following cases:

  | q | proved range |
  |---|---|
  | 2 | d ≤ 25 |
  | 3 | d ≤ 16 |
  | 4 | d ≤ 13 |
  | 5 | d ≤ 11 |
  | 7 | d ≤ 10 |
  | 8 | d ≤ 10 |
  | 9 | d ≤ 8 |

  Hence **the function-field analogue of Legendre's conjecture holds for every q when d ≤ 10.**
- **Zeros.** Every Hayes $L$-function has degree exactly $m-2$, where $u^m$ is its conductor, with all inverse roots of absolute value $\sqrt q$ (Proposition 7.1); the computed numbers of $L$-functions of each degree match $q^{m-1}-q^{m-2}$ exactly.
- **Fluctuations and form factor.** For odd $q$, the variance of $\Psi$ across intervals follows the Keating–Rudnick value $(d-2)q^{d+1}$ already at $q=3$. The form factor of the $L$-functions equals an exact arithmetic diagonal for $n\le d-1$ (Proposition 7.2), and the CUE value beyond.
- **Characteristic 2.** The Legendre intervals are the squares of the Hayes group, and every element has the form $h^2+tb^2$. Over them, the variance differs from the full-group value by factors between 0.33 and 21. The discrepancy is carried entirely by correlations between quadratic twists of the $L$-functions, spread over many twists. Its explanation is posed as an open problem; working notes are in [`notes/char2_research.md`](notes/char2_research.md).

## Layout

```
├── paper/          legendre_explicit.tex / .pdf, tables/ and figures/ generated by code/make_paper.py
├── code/
│   ├── fqlib.py, small_q_gf.py, fflib.py   finite-field arithmetic (tables), slow reference code
│   ├── hayes_fft_fq.py                     Hayes-group basis, discrete log, floating-point explicit formula
│   ├── hayes_exact.py                      the same in exact modular arithmetic (two primes + CRT)
│   ├── explicit_scan.py / exact_scan.py    scans over (q, d); exact_scan is the certified one
│   ├── form_factor.py, zero_stats.py       form factor and zeros of the Hayes L-functions
│   ├── char2_corr.py, char2_probe.py       characteristic-2 diagnostics
│   ├── test_*.py                           cross-checks (brute force, exact vs float, field code)
│   └── make_paper.py, run_all.py, open_data.py
├── data/           CSV results; open_regime_* are brute-force reference counts from the companion repository
└── notes/          research notes
```

## Reproducing

```bash
pip install -r requirements.txt
python code/run_all.py --quick     # tests, then tables and figures from the committed data
python code/run_all.py             # everything from scratch (a few hours; about 10 GB RAM for q=8, d=10)
cd paper && pdflatex legendre_explicit.tex && pdflatex legendre_explicit.tex
```
